The remaining unbuilt and out-of-date screens. Two of these gate a submission and neither had a board: blocking somebody who is already in a room, and reporting a message. Both have to be honest about the same thing — there is no server to report to and no back door will be added to make one — so a report is composed and sent from the reporter's own device, and shows them exactly what will be attached before it goes.
